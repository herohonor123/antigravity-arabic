# قواعد تنسيق اللغة العربية والنصوص ثنائية الاتجاه (Arabic BiDi & RTL Formatting Rules)

عند الرد باللغة العربية، يجب على الموديل (Agent) الالتزام بالقواعد التالية لضمان عرض النص العربي بأعلى جودة ومنع تداخل الحروف أو انعكاس الكلمات مع الإنجليزية والأكواد:

## 1. عزل المصطلحات الإنجليزية والأكواد (BiDi Isolation)
- **إلزامية الـ Backticks:** أي كلمة أو مصطلح إنجليزي، اسم مكتبة، أمر طرفية، مسار ملف، أو اسم دالة/متغير داخل سطر عربي **يجب** وضعه داخل علامتي التنصيص المائلتين (`` `code` ``).
  - ✅ **صحيح:** لتثبيت الحزمة استخدم الأمر `npm install` ثم تابع.
  - ❌ **خاطئ:** لتثبيت الحزمة استخدم الأمر npm install ثم تابع.
- **تجنب تلاصق الإنجليزية مع الرموز العربية:** اترك مسافة واضحة قبل وبعد أي رمز أو مصطلح إنجليزي.

## 2. تنسيق القوائم ثنائية اللغة (Bilingual Lists)
عند عمل قوائم تحتوي على مصطلح إنجليزي وشرحه بالعربي:
- ابدأ بالعنصر العربي أولاً إن أمكن، أو ضع المصطلح الإنجليزي داخل كود عريض:
  - ✅ **صحيح:** `- **`API Endpoint`**: الرابط المخصص للاتصال بالسيرفر.`
  - ✅ **صحيح:** `- **واجهة برمجة التطبيقات (`API`)**: تمكن الأنظمة من تبادل البيانات.`

## 3. علامات الترقيم والأقواس (Punctuation & Brackets)
- لا تضع أقواس إنجليزية فارغة أو تبدأ السطر بأقواس مختلطة.
- ضع الأقواس والترقيم ملاصقة للنص التابع لها بالكامل لتفادي قلب القوسين `(` و `)`.
- استخدم علامات الترقيم العربية (`،` بدلاً من `,` و `؟` بدلاً من `?`) في الفقرات العربية الخالصة.

## 4. كتل الأكواد (Code Blocks)
- جميع كتل الأكواد (Fenced Code Blocks ```) يجب أن تكون منفصلة تماماً بأسطر فارغة قبلها وبعدها، وتظل بالإنجليزية LTR دون خلط تعليقات عربية على نفس سطر الكود البرمجي إلا إذا كانت معزولة بشكل صحيح.
